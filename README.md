# SD_Portfolio

A premium, highly interactive personal portfolio built with **Next.js**, **Framer Motion**, and **Three.js**.

## ✨ Features

- 🌐 Floating glassmorphism navbar with route-based active indicators
- 🎨 Animated hero section with a live Three.js particle background
- 🧠 Bento-grid skills section with tech stack, timezone & collaboration cards
- 💼 Curated Work section with 3D tilt cards and mouse-following VIEW DETAILS cursor
- 💬 Auto-scrolling testimonials marquee
- 📬 Contact CTA with footer

## 🛠️ Tech Stack

- [Next.js 14](https://nextjs.org/)
- [Framer Motion](https://www.framer.com/motion/)
- [Three.js](https://threejs.org/)
- [Lucide React](https://lucide.dev/)
- CSS Modules

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
